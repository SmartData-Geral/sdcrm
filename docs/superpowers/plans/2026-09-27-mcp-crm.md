# MCP do SDCRM — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Servidor MCP embutido no backend do SDCRM, em `/api/mcp/{chave}`, com 18 ferramentas para ler e operar leads/oportunidades, funil, histórico e indicadores, autenticado pelas chaves de integração com escopos `mcp:read` / `mcp:write`.

**Architecture:** Um pacote `backend/mcp_crm/` cria um `MCPServer` (SDK `mcp==2.0.0`), servido por Streamable HTTP sem estado e montado no FastAPI atrás de um wrapper ASGI que valida a chave e injeta o id dela num header interno. Cada ferramenta roda dentro do gerenciador de contexto `executar_ferramenta`, que abre a sessão de banco, revalida a chave, confere o escopo, traduz exceções e grava o log de integração. As ferramentas chamam os services existentes; nenhuma regra de negócio é duplicada.

**Tech Stack:** Python 3.11 (Docker) / 3.14 (local), FastAPI 0.135.2, Starlette 1.0.0, SQLAlchemy 2.0, Pydantic 2.12.5, SDK `mcp==2.0.0`, `unittest` + `unittest.mock`.

**Spec:** `docs/superpowers/specs/2026-09-27-mcp-crm-design.md`

## Global Constraints

- Dependências fixas (iguais às do SDFin, que roda o mesmo SDK em produção no Python 3.11): `fastapi==0.135.2`, `starlette==1.0.0`, `uvicorn[standard]==0.42.0`, `pydantic==2.12.5`, `pydantic-settings==2.13.1`, `mcp==2.0.0`, `tzdata==2025.2`.
- O `empId` usado em toda consulta e gravação vem **sempre** da chave (`ContextoMCP.empId`); nenhuma ferramenta recebe empresa por parâmetro.
- Escopos: leitura exige `mcp:read` ou `mcp:write`; escrita exige `mcp:write`.
- Mensagem de chave recusada: `"Chave de API invalida ou revogada"` (idêntica à da API `/api/v1`).
- Mensagem de oportunidade inexistente, de outra empresa ou inativa: `"Oportunidade não encontrada"`.
- Prefixo de anotação feita pelo MCP: `"[via MCP · <nome da chave>] "`.
- Datas em `YYYY-MM-DD`; "hoje" é calculado no fuso `America/Sao_Paulo`.
- Paginação: `por_pagina` limitado a 50.
- Nomes de ferramenta, parâmetro e mensagem em português, sem prefixo de coluna (`titulo`, não `opoTitulo`).
- Log de cada chamada: `rota="mcp:<ferramenta>"`, `metodo="TOOL"`.
- Testes: `unittest` + `unittest.mock`, sem banco real. Rodar da raiz do repo com
  `.venv/Scripts/python -m unittest backend.tests.<modulo> -v` (no Linux/Docker: `python -m unittest ...`).

## Ajustes em relação à especificação

1. **Gerenciador de contexto em vez de decorador.** A spec (seção 6) fala em `@ferramenta(escrita=...)`.
   O SDK monta o esquema de entrada inspecionando a assinatura da função registrada; um
   decorador que troca a assinatura quebra esse esquema. O plano usa
   `with executar_ferramenta(ctx, nome, escrita=..., argumentos=dict(locals()), opo_id=...) as sessao:`
   dentro de cada ferramenta. As responsabilidades são exatamente as da seção 6.
2. **Pins de dependências.** A spec só previa `mcp==2.0.0`, mas ele exige `pydantic>=2.12` e
   `uvicorn>=0.31.1`, incompatíveis com os pins atuais (`pydantic==2.9.2`, `uvicorn==0.30.6`).
   O `.venv` local já está nas versões novas; o Task 1 alinha o `requirements.txt` a elas.
   Entra também `tzdata`, porque o Windows não traz a base de fusos que `ZoneInfo` usa.
3. **Sem apagar campo pelo MCP.** Em `atualizar_oportunidade`, parâmetro omitido ou `null`
   significa "não mexer". Não há como limpar um campo pelo MCP nesta fase.

A spec é atualizada no Task 11 para refletir os itens 1 e 2.

## Review Focus

1. **Chave revogada com o conector aberto** — a chamada seguinte deve falhar com "Chave de API invalida ou revogada", mesmo sem reconectar (teste em Task 3: `carregar_contexto` com chave revogada).
2. **Header `x-sdcrm-ich-id` forjado pelo cliente** — deve ser descartado e substituído pelo id da chave autenticada; nunca pode escolher outra chave/empresa (teste em Task 4).
3. **Oportunidade de outra empresa ou inativa passada por id** — toda ferramenta deve responder "Oportunidade não encontrada" antes de gravar qualquer coisa (teste em Task 6 para o helper e nos testes de escrita dos Tasks 9 e 10).
4. **`marcar_perdido` com motivo de outra empresa** — deve falhar antes de gravar o motivo ou o status (teste em Task 10).
5. **Lead sem e-mail nem telefone utilizável via `criar_lead`** — deve voltar a mensagem de validação da API em português, sem "Value error," e sem traceback (teste em Task 3 para a tradução e Task 9 para a ferramenta).

"""
Identidade de cada chamada de ferramenta MCP.

O wrapper ASGI (autenticacao.py) valida a chave uma vez por requisição HTTP e injeta
o id dela em HEADER_ICH_ID. Aqui a chave é recarregada e revalidada a cada chamada,
para que revogar a chave corte o acesso mesmo com o conector já conectado.
"""

from __future__ import annotations

from dataclasses import dataclass
from typing import Any

from sqlalchemy.orm import Session

from ..models.integracao_chave import IntegracaoChave
from ..services import integracao_chave_service

HEADER_ICH_ID = "x-sdcrm-ich-id"
ESCOPO_LEITURA = "mcp:read"
ESCOPO_ESCRITA = "mcp:write"
ESCOPOS_MCP = frozenset({ESCOPO_LEITURA, ESCOPO_ESCRITA})

MENSAGEM_CHAVE_RECUSADA = "Chave de API invalida ou revogada"


class ErroMCP(Exception):
    """Falha de uso ou de permissão com mensagem pronta para o Claude."""

    def __init__(self, mensagem: str, status_http: int = 400, resultado: str = "bad_request") -> None:
        super().__init__(mensagem)
        self.mensagem = mensagem
        self.status_http = status_http
        self.resultado = resultado


@dataclass
class ContextoMCP:
    db: Session
    ichId: int
    empId: int
    nome: str
    escopos: frozenset[str]
    usuResponsavelPadraoId: int | None
    # Preenchido pela ferramenta quando ela descobre a oportunidade (ex.: criar_lead),
    # para o log de integração apontar para ela.
    opo_id: int | None = None


def escopos_da_chave(chave: Any) -> frozenset[str]:
    return frozenset(e.strip() for e in (chave.ichEscopos or "").split(",") if e.strip())


def ich_id_do_contexto(ctx: Any) -> int:
    headers = getattr(ctx, "headers", None) or {}
    valor = headers.get(HEADER_ICH_ID)
    try:
        return int(valor)
    except (TypeError, ValueError):
        raise ErroMCP(
            "Requisição MCP sem autenticação. Verifique a URL do conector.",
            status_http=401,
            resultado="unauthorized",
        )


def carregar_contexto(db: Session, ich_id: int) -> ContextoMCP:
    chave = db.get(IntegracaoChave, ich_id)
    if chave is None or not integracao_chave_service.chave_utilizavel(chave):
        raise ErroMCP(MENSAGEM_CHAVE_RECUSADA, status_http=401, resultado="unauthorized")
    escopos = escopos_da_chave(chave)
    if not escopos & ESCOPOS_MCP:
        raise ErroMCP(MENSAGEM_CHAVE_RECUSADA, status_http=401, resultado="unauthorized")
    integracao_chave_service.registrar_uso(db, chave)
    db.commit()
    return ContextoMCP(
        db=db,
        ichId=chave.ichId,
        empId=chave.ichEmpId,
        nome=chave.ichNome,
        escopos=escopos,
        usuResponsavelPadraoId=chave.ichUsuResponsavelPadraoId,
    )

```python
"""
Execução padronizada de uma ferramenta MCP.

Toda ferramenta faz:

    with executar_ferramenta(ctx, "nome", escrita=..., argumentos=dict(locals()), opo_id=...) as sessao:
        ...

É um gerenciador de contexto, e não um decorador, porque o SDK monta o esquema de
entrada lendo a assinatura da função registrada; um decorador que a trocasse quebraria
esse esquema.
"""

from __future__ import annotations

import logging
import time
from contextlib import contextmanager
from typing import Any, Iterator

from fastapi import HTTPException
from fastapi.encoders import jsonable_encoder
from mcp.server.mcpserver.exceptions import ToolError
from pydantic import ValidationError

from ..database import SessionLocal
from ..services import integracao_log_service
from .sessao import (
    ESCOPO_ESCRITA,
    ContextoMCP,
    ErroMCP,
    carregar_contexto,
    ich_id_do_contexto,
)

logger = logging.getLogger(__name__)

MENSAGEM_ERRO_INTERNO = "Erro interno ao executar a ferramenta."

_RESULTADO_POR_STATUS = {
    400: "bad_request",
    401: "unauthorized",
    403: "forbidden",
    404: "not_found",
    409: "conflict",
}


def _mensagens_de_validacao(exc: ValidationError) -> str:
    partes = []
    for erro in exc.errors():
        msg = str(erro.get("msg", "")).removeprefix("Value error, ")
        local = ".".join(str(p) for p in erro.get("loc", ()) if p != "__root__")
        partes.append(f"{local}: {msg}" if local else msg)
    return "; ".join(partes) or "Parâmetros inválidos."


def traduzir_excecao(exc: BaseException) -> tuple[int, str, str]:
    """(status_http, resultado, mensagem para o Claude)."""
    if isinstance(exc, ErroMCP):
        return exc.status_http, exc.resultado, exc.mensagem
    if isinstance(exc, HTTPException):
        status = int(exc.status_code)
        return status, _RESULTADO_POR_STATUS.get(status, "error"), str(exc.detail)
    # ValidationError é subclasse de ValueError: precisa vir antes.
    if isinstance(exc, ValidationError):
        return 400, "bad_request", _mensagens_de_validacao(exc)
    if isinstance(exc, ValueError):
        return 400, "bad_request", str(exc)
    return 500, "error", MENSAGEM_ERRO_INTERNO


def exigir_escopo(sessao: ContextoMCP, escrita: bool) -> None:
    if escrita and ESCOPO_ESCRITA not in sessao.escopos:
        raise ErroMCP(
            "Esta chave não tem permissão de escrita (escopo mcp:write).",
            status_http=403,
            resultado="forbidden",
        )


@contextmanager
def executar_ferramenta(
    ctx: Any,
    nome: str,
    *,
    escrita: bool,
    argumentos: dict,
    opo_id: int | None = None,
) -> Iterator[ContextoMCP]:
    inicio = time.perf_counter()
    db = SessionLocal()
    sessao: ContextoMCP | None = None
    status_http, resultado, erro = 200, "ok", None
    try:
        try:
            sessao = carregar_contexto(db, ich_id_do_contexto(ctx))
            exigir_escopo(sessao, escrita)
            sessao.opo_id = opo_id
            yield sessao
        except Exception as exc:
            try:
                db.rollback()
            except Exception:
                logger.exception("Falha no rollback da ferramenta MCP %s", nome)
            status_http, resultado, mensagem = traduzir_excecao(exc)
            erro = {"detalhe": mensagem}
            if status_http >= 500:
                logger.exception("Erro inesperado na ferramenta MCP %s", nome)
            raise ToolError(mensagem) from exc
    finally:
        integracao_log_service.registrar(
            db,
            rota=f"mcp:{nome}",
            metodo="TOOL",
            status_http=status_http,
            resultado=resultado,
            emp_id=sessao.empId if sessao else None,
            ich_id=sessao.ichId if sessao else None,
            opo_id=sessao.opo_id if sessao else opo_id,
            payload=jsonable_encoder({k: v for k, v in (argumentos or {}).items() if k != "ctx"}),
            erro=erro,
            duracao_ms=int((time.perf_counter() - inicio) * 1000),
        )
        db.close()
```

```python
"""
Wrapper ASGI do servidor MCP: valida a chave de integração antes do SDK.

A chave chega no primeiro segmento do caminho (/api/mcp/<chave>), porque o conector
personalizado do claude.ai não envia headers próprios, ou no header X-API-Key
(n8n, Claude Code). O id da chave validada segue para as ferramentas em HEADER_ICH_ID;
qualquer header x-sdcrm-* vindo de fora é descartado antes.
"""

from __future__ import annotations

import json

import anyio

from ..database import SessionLocal
from ..services import integracao_chave_service, integracao_log_service
from .sessao import ESCOPOS_MCP, HEADER_ICH_ID, MENSAGEM_CHAVE_RECUSADA, escopos_da_chave

MONTAGEM = "/api/mcp"
_PREFIXO_CHAVE = f"{integracao_chave_service.PREFIXO_LITERAL}_"


def caminho_efetivo(scope: dict) -> str:
    """Caminho dentro do mount. Mesmo tratamento do SDFin para root_path e proxy."""
    path = scope.get("path", "/") or "/"
    root = scope.get("root_path", "") or ""
    if root and path.startswith(root):
        return path[len(root):] or "/"
    if MONTAGEM + "/" in path:
        return path[path.index(MONTAGEM + "/") + len(MONTAGEM):]
    return path


def _header(scope: dict, nome: bytes) -> str | None:
    for chave, valor in scope.get("headers", []):
        if chave.lower() == nome:
            return valor.decode("latin-1")
    return None


def _ip(scope: dict) -> str | None:
    encaminhado = _header(scope, b"x-forwarded-for")
    if encaminhado:
        return encaminhado.split(",")[0].strip()[:64]
    cliente = scope.get("client")
    return cliente[0] if cliente else None


def autenticar_chave(
    valor: str | None, *, metodo: str, ip: str | None, user_agent: str | None
) -> int | None:
    """Id da chave se ela é válida e tem algum escopo mcp:*; senão loga e devolve None."""
    db = SessionLocal()
    try:
        chave = integracao_chave_service.autenticar(db, valor)
        if chave is not None and escopos_da_chave(chave) & ESCOPOS_MCP:
            return chave.ichId
        integracao_log_service.registrar(
            db,
            rota="mcp",
            metodo=metodo,
            status_http=401,
            resultado="unauthorized",
            prefixo_informado=integracao_chave_service.prefixo_para_log(valor),
            ip=ip,
            user_agent=user_agent,
        )
        return None
    finally:
        db.close()


class AutenticacaoMCPASGI:
    def __init__(self, app) -> None:
        self.app = app

    async def __call__(self, scope, receive, send) -> None:
        if scope["type"] != "http":
            await self.app(scope, receive, send)
            return

        efetivo = caminho_efetivo(scope)
        segmento = efetivo.lstrip("/").split("/", 1)[0]
        if segmento.startswith(_PREFIXO_CHAVE):
            valor = segmento
            resto = efetivo[len("/" + segmento):] or "/"
        else:
            valor = _header(scope, b"x-api-key")
            resto = efetivo or "/"

        ich_id = await anyio.to_thread.run_sync(
            lambda: autenticar_chave(
                valor,
                metodo=scope.get("method", ""),
                ip=_ip(scope),
                user_agent=_header(scope, b"user-agent"),
            )
        )
        if ich_id is None:
            await self._negar(send)
            return

        headers = [
            (k, v)
            for k, v in scope.get("headers", [])
            if not k.lower().startswith(b"x-sdcrm-") and k.lower() != b"x-api-key"
        ]
        headers.append((HEADER_ICH_ID.encode(), str(ich_id).encode()))

        novo = dict(scope)
        novo["path"] = resto
        novo["raw_path"] = resto.encode()
        novo["root_path"] = ""
        novo["headers"] = headers
        await self.app(novo, receive, send)

    @staticmethod
    async def _negar(send) -> None:
        corpo = json.dumps({"detail": MENSAGEM_CHAVE_RECUSADA}).encode()
        await send(
            {
                "type": "http.response.start",
                "status": 401,
                "headers": [(b"content-type", b"application/json")],
            }
        )
        await send({"type": "http.response.body", "body": corpo})
```

"""JSON enxuto das respostas do MCP (spec, seção 5.3)."""

from __future__ import annotations

from dataclasses import dataclass, field
from datetime import date, datetime
from typing import Any, Iterable

from sqlalchemy import select
from sqlalchemy.orm import Session

from ..core.links import url_da_oportunidade
from ..models.como_conheceu import ComoConheceu
from ..models.etapa_kanban import EtapaKanban
from ..models.motivo_cancelamento import MotivoCancelamento
from ..models.produto import Produto
from ..models.usuario import Usuario

_TIPO_FECHAMENTO = {0: "recorrencia", 1: "projeto"}


@dataclass
class Nomes:
    etapas: dict[int, tuple[str, str]] = field(default_factory=dict)
    usuarios: dict[int, str] = field(default_factory=dict)
    produtos: dict[int, str] = field(default_factory=dict)
    origens: dict[int, str] = field(default_factory=dict)
    motivos: dict[int, str] = field(default_factory=dict)


def _ids(itens: Iterable[Any], atributo: str) -> set[int]:
    return {v for v in (getattr(i, atributo, None) for i in itens) if v is not None}


def _mapa(db: Session, col_id, col_nome, ids: set[int]) -> dict[int, str]:
    if not ids:
        return {}
    return {i: n for i, n in db.execute(select(col_id, col_nome).where(col_id.in_(ids))).all()}


def carregar_nomes(db: Session, oportunidades: Iterable[Any]) -> Nomes:
    oportunidades = list(oportunidades)
    nomes = Nomes()
    etapas = _ids(oportunidades, "opoEtkId")
    if etapas:
        nomes.etapas = {
            i: (n, p)
            for i, n, p in db.execute(
                select(EtapaKanban.etkId, EtapaKanban.etkNome, EtapaKanban.etkPipeline).where(
                    EtapaKanban.etkId.in_(etapas)
                )
            ).all()
        }
    nomes.usuarios = _mapa(db, Usuario.usuId, Usuario.usuNome, _ids(oportunidades, "opoUsuResponsavelId"))
    nomes.produtos = _mapa(db, Produto.proId, Produto.proNome, _ids(oportunidades, "opoProId"))
    nomes.origens = _mapa(db, ComoConheceu.ccoId, ComoConheceu.ccoNome, _ids(oportunidades, "opoCcoId"))
    nomes.motivos = _mapa(db, MotivoCancelamento.mcaId, MotivoCancelamento.mcaNome, _ids(oportunidades, "opoMcaId"))
    return nomes


def carregar_autores(db: Session, historicos: Iterable[Any]) -> dict[int, str]:
    return _mapa(db, Usuario.usuId, Usuario.usuNome, _ids(list(historicos), "ophUsuId"))


def _data(valor: date | datetime | None) -> str | None:
    return valor.isoformat() if valor is not None else None


def _num(valor: Any) -> float | None:
    return float(valor) if valor is not None else None


def _ref(mapa: dict[int, str], id_: int | None) -> dict | None:
    if id_ is None:
        return None
    return {"id": id_, "nome": mapa.get(id_)}


def _etapa(nomes: Nomes, etk_id: int | None) -> dict | None:
    if etk_id is None:
        return None
    nome, pipeline = nomes.etapas.get(etk_id, (None, None))
    return {"id": etk_id, "nome": nome, "pipeline": pipeline}


def status_de(opo: Any) -> str:
    return opo.opoStatusFechamento or "ativo"


def resumo_oportunidade(opo: Any, nomes: Nomes) -> dict:
    return {
        "id": opo.opoId,
        "titulo": opo.opoTitulo,
        "contato": opo.opoNomeContato,
        "empresa": opo.opoEmpresaContato,
        "status": status_de(opo),
        "etapa": _etapa(nomes, opo.opoEtkId),
        "responsavel": _ref(nomes.usuarios, opo.opoUsuResponsavelId),
        "temperatura": opo.opoTemperatura,
        "lead_score": opo.opoLeadScore,
        "valor": _num(opo.opoValorOportunidade),
        "data_ultimo_contato": _data(opo.opoDataUltimoContato),
    }


def oportunidade_completa(opo: Any, nomes: Nomes) -> dict:
    dados = {
        **resumo_oportunidade(opo, nomes),
        "email": opo.opoEmail,
        "telefone": opo.opoTelefone,
        "solucao": opo.opoSolucao,
        "produto": _ref(nomes.produtos, opo.opoProId),
        "origem": _ref(nomes.origens, opo.opoCcoId),
        "motivo_perda": _ref(nomes.motivos, opo.opoMcaId),
        "reuniao_confirmada": opo.opoReuniaoConfirmada,
        "proposta_enviada": opo.opoPropostaEnviada,
        "receita_pontual": opo.opoReceitaPontual,
        "data_recebimento": _data(opo.opoDataRecebimento),
        "dores": opo.opoDoresMotivadores,
        "comentarios": opo.opoComentarios,
        "origem_externa": {
            "sistema": getattr(opo, "opoOrigemSistema", None),
            "utm_source": getattr(opo, "opoUtmSource", None),
            "utm_campaign": getattr(opo, "opoUtmCampaign", None),
        },
        "criado_em": _data(opo.opoDataCriacao),
        "atualizado_em": _data(opo.opoDataAtualizacao),
        "url": url_da_oportunidade(opo.opoId),
    }
    if status_de(opo) != "ativo":
        dados["fechamento"] = {
            "data": _data(opo.opoDataFechamento),
            "tipo": _TIPO_FECHAMENTO.get(opo.opoFechadoRecorrencia),
            "valor": _num(opo.opoValorFechado),
        }
    return dados


def historico_item(h: Any, autores: dict[int, str]) -> dict:
    return {
        "id": h.ophId,
        "data": _data(h.ophDataRegistro),
        "autor": _ref(autores, h.ophUsuId),
        "conteudo": h.ophConteudo,
    }
```

"""Peças compartilhadas pelas ferramentas."""

from __future__ import annotations

from datetime import date, datetime
from zoneinfo import ZoneInfo

from sqlalchemy import select

from ...exceptions import BadRequestError, NotFoundError
from ...models.como_conheceu import ComoConheceu
from ...models.motivo_cancelamento import MotivoCancelamento
from ...models.oportunidade import Oportunidade

from ...services import oportunidade_service
from ..serializacao import carregar_nomes, oportunidade_completa
from ..sessao import ContextoMCP

FUSO = ZoneInfo("America/Sao_Paulo")
MAX_POR_PAGINA = 50


def hoje() -> date:
    return datetime.now(FUSO).date()


def limitar_pagina(pagina: int, por_pagina: int) -> tuple[int, int]:
    return max(1, pagina), min(max(1, por_pagina), MAX_POR_PAGINA)


def obter_oportunidade_ativa(sessao: ContextoMCP, opo_id: int) -> Oportunidade:
    """Inexistente, de outra empresa ou inativa: sempre a mesma resposta."""
    opo = oportunidade_service.get_oportunidade(sessao.db, opo_id, sessao.empId)
    if not opo.opoAtivo:
        raise NotFoundError("Oportunidade não encontrada")
    return opo


def responder_oportunidade(sessao: ContextoMCP, opo) -> dict:
    return oportunidade_completa(opo, carregar_nomes(sessao.db, [opo]))


def prefixar(sessao: ContextoMCP, texto: str) -> str:
    return f"[via MCP · {sessao.nome}] {texto.strip()}"


def _exigir(sessao: ContextoMCP, stmt, rotulo: str, valor: int) -> None:
    if sessao.db.scalar(stmt) is None:
        raise BadRequestError(f"{rotulo} {valor} não existe nesta empresa.")


def validar_produto(sessao: ContextoMCP, produto_id: int) -> None:
    _exigir(
        sessao,
        select(Produto.proId).where(
            Produto.proId == produto_id, Produto.proEmpId == sessao.empId, Produto.proAtivo.is_(True)
        ),
        "Produto",
        produto_id,
    )


def validar_origem(sessao: ContextoMCP, origem_id: int) -> None:
    _exigir(
        sessao,
        select(ComoConheceu.ccoId).where(
            ComoConheceu.ccoId == origem_id,
            ComoConheceu.ccoEmpId == sessao.empId,
            ComoConheceu.ccoAtivo.is_(True),
        ),
        "Origem",
        origem_id,
    )


def validar_motivo(sessao: ContextoMCP, motivo_id: int) -> None:
    _exigir(
        sessao,
        select(MotivoCancelamento.mcaId).where(
            MotivoCancelamento.mcaId == motivo_id,
            MotivoCancelamento.mcaEmpId == sessao.empId,
            MotivoCancelamento.mcaAtivo.is_(True),
        ),
        "Motivo de perda",
        motivo_id,
    )


def validar_responsavel(sessao: ContextoMCP, usuario_id: int) -> None:
    _exigir(
        sessao,
        select(Usuario.usuId)
        .join(UsuarioEmpresa, UsuarioEmpresa.useUsuId == Usuario.usuId)
        .where(
            Usuario.usuId == usuario_id,
            UsuarioEmpresa.useEmpId == sessao.empId,
            Usuario.usuAtivo.is_(True),
        ),
        "Responsável",
        usuario_id,
    )

from sqlalchemy import select

from mcp.server.mcpserver import Context

from ...models.como_conheceu import ComoConheceu
from ...models.empresa import Empresa
from ...models.etapa_kanban import EtapaKanban
from ...models.motivo_cancelamento import MotivoCancelamento
from ...models.produto import Produto
from ...models.usuario import Usuario
from ...models.usuario_empresa import UsuarioEmpresa
from ..ferramenta import executar_ferramenta
from ..servidor import mcp
from ._comum import hoje


@mcp.tool()
def contexto(ctx: Context) -> dict:
    """Situa o agente: empresa da chave, nome e escopos da chave, responsável padrão
    (autor das anotações feitas pelo MCP), data de hoje e pipelines de venda.
    Chame esta ferramenta primeiro."""
    argumentos = dict(locals())
    with executar_ferramenta(ctx, "contexto", escrita=False, argumentos=argumentos) as s:
        empresa = s.db.get(Empresa, s.empId)
        responsavel = s.db.get(Usuario, s.usuResponsavelPadraoId) if s.usuResponsavelPadraoId else None
        pipelines = s.db.scalars(
            select(EtapaKanban.etkPipeline)
            .where(EtapaKanban.etkEmpId == s.empId, EtapaKanban.etkAtivo.is_(True))
            .distinct()
            .order_by(EtapaKanban.etkPipeline)
        ).all()
        return {
            "empresa": {"id": s.empId, "nome": empresa.empNome if empresa else None},
            "chave": {"nome": s.nome, "escopos": sorted(s.escopos)},
            "responsavel_padrao": (
                {"id": responsavel.usuId, "nome": responsavel.usuNome} if responsavel else None
            ),
            "hoje": hoje().isoformat(),
            "pipelines": list(pipelines),
        }


@mcp.tool()
def listar_cadastros(ctx: Context) -> dict:
    """Lista, numa chamada, os cadastros ativos usados para filtrar e editar
    oportunidades: etapas por pipeline (na ordem do kanban), produtos, origens
    ("como conheceu"), motivos de perda e responsáveis. Use para descobrir IDs."""
    argumentos = dict(locals())
    with executar_ferramenta(ctx, "listar_cadastros", escrita=False, argumentos=argumentos) as s:
        db, emp = s.db, s.empId
        etapas = db.scalars(
            select(EtapaKanban)
            .where(EtapaKanban.etkEmpId == emp, EtapaKanban.etkAtivo.is_(True))
            .order_by(EtapaKanban.etkPipeline, EtapaKanban.etkOrdem, EtapaKanban.etkId)
        ).all()
        produtos = db.scalars(
            select(Produto).where(Produto.proEmpId == emp, Produto.proAtivo.is_(True)).order_by(Produto.proNome)
        ).all()
        origens = db.scalars(
            select(ComoConheceu)
            .where(ComoConheceu.ccoEmpId == emp, ComoConheceu.ccoAtivo.is_(True))
            .order_by(ComoConheceu.ccoNome)
        ).all()
        motivos = db.scalars(
            select(MotivoCancelamento)
            .where(MotivoCancelamento.mcaEmpId == emp, MotivoCancelamento.mcaAtivo.is_(True))
            .order_by(MotivoCancelamento.mcaNome)
        ).all()
        responsaveis = db.execute(
            select(Usuario.usuId, Usuario.usuNome, Usuario.usuEmail)
            .join(UsuarioEmpresa, UsuarioEmpresa.useUsuId == Usuario.usuId)
            .where(UsuarioEmpresa.useEmpId == emp, Usuario.usuAtivo.is_(True))
            .order_by(Usuario.usuNome)
        ).all()

        por_pipeline: dict[str, list[dict]] = {}
        for e in etapas:
            por_pipeline.setdefault(e.etkPipeline, []).append({"id": e.etkId, "nome": e.etkNome, "ordem": e.etkOrdem})
        return {
            "etapas": por_pipeline,
            "produtos": [{"id": p.proId, "nome": p.proNome} for p in produtos],
            "origens": [{"id": o.ccoId, "nome": o.ccoNome, "grupo": o.ccoGrupo} for o in origens],
            "motivos_perda": [{"id": m.mcaId, "nome": m.mcaNome} for m in motivos],
            "responsaveis": [{"id": i, "nome": n, "email": e} for i, n, e in responsaveis],
        }
```

from datetime import date
from typing import Annotated, Literal

from pydantic import Field

from mcp.server.mcpserver import Context

from ...models.oportunidade import Oportunidade
from ...services import oportunidade_historico_service, oportunidade_service
from ..ferramenta import executar_ferramenta
from ..serializacao import carregar_autores, carregar_nomes, historico_item, oportunidade_completa, resumo_oportunidade, status_de
from ..servidor import mcp
from ._comum import limitar_pagina, obter_oportunidade_ativa

Status = Literal["ativo", "ganho", "perdido", "stand-by"]
Temperatura = Literal["quente", "morno", "frio"]


@mcp.tool()
def buscar_oportunidades(
    ctx: Context,
    texto: str | None = None,
    status: Status | None = None,
    etapa_id: int | None = None,
    pipeline: str | None = None,
    responsavel_id: int | None = None,
    produto_id: int | None = None,
    temperatura: Temperatura | None = None,
    ultimo_contato_de: date | None = None,
    ultimo_contato_ate: date | None = None,
    pagina: Annotated[int, Field(ge=1)] = 1,
    por_pagina: Annotated[int, Field(ge=1)] = 20,
) -> dict:
    """Busca oportunidades/leads ativos no CRM, das mais novas para as mais antigas.
    `texto` procura em título, nome do contato, empresa e e-mail. Para achar leads

from ...models.etapa_kanban import EtapaKanban

@mcp.tool()
def resumo_funil(ctx: Context, pipeline: str | None = None) -> dict:
    """Foto do kanban: quantidade e valor das oportunidades ativas (sem fechamento)
    em cada etapa de um pipeline, na ordem do funil. Sem `pipeline`, usa o primeiro."""
    argumentos = dict(locals())
    with executar_ferramenta(ctx, "resumo_funil", escrita=False, argumentos=argumentos) as s:
        db, emp = s.db, s.empId
        ativa = (EtapaKanban.etkEmpId == emp, EtapaKanban.etkAtivo.is_(True))
        if not pipeline:
            pipeline = db.scalar(
                select(EtapaKanban.etkPipeline).where(*ativa).order_by(EtapaKanban.etkOrdem, EtapaKanban.etkId).limit(1)
            )
        if not pipeline:
            return {"pipeline": None, "etapas": [], "total_quantidade": 0, "total_valor": 0.0}

        etapas = db.scalars(
            select(EtapaKanban)
            .where(*ativa, EtapaKanban.etkPipeline == pipeline)
            .order_by(EtapaKanban.etkOrdem, EtapaKanban.etkId)
        ).all()
        linhas = []
        if etapas:
            linhas = db.execute(
                select(
                    Oportunidade.opoEtkId,
                    func.count(Oportunidade.opoId),
                    func.coalesce(func.sum(Oportunidade.opoValorOportunidade), 0),
                )
                .where(
                    Oportunidade.opoEmpId == emp,
                    Oportunidade.opoAtivo.is_(True),
                    Oportunidade.opoStatusFechamento.is_(None),
                    Oportunidade.opoEtkId.in_([e.etkId for e in etapas]),
                )
                .group_by(Oportunidade.opoEtkId)
            ).all()
        por_etapa = {etk: (int(qtd), float(valor)) for etk, qtd, valor in linhas}
        itens = []
        for e in etapas:
            qtd, valor = por_etapa.get(e.etkId, (0, 0.0))
            itens.append({"etapa": {"id": e.etkId, "nome": e.etkNome}, "quantidade": qtd, "valor_total": valor})
        return {
            "pipeline": pipeline,
            "etapas": itens,
            "total_quantidade": sum(i["quantidade"] for i in itens),
            "total_valor": round(sum(i["valor_total"] for i in itens), 2),
        }

def _sem_alteracao(s, opo, aviso: str) -> dict:
    return {**responder_oportunidade(s, opo), "aviso": aviso}


@mcp.tool()
def marcar_ganho(
    ctx: Context,
    oportunidade_id: int,
    data_fechamento: date,
    tipo: Literal["recorrencia", "projeto"],
    valor_fechado: Annotated[float, Field(gt=0)],
) -> dict:
    """Marca a oportunidade como GANHA. Altera MRR e indicadores: confirme com o
    usuário data, tipo (recorrencia = receita mensal; projeto = receita única) e valor
    antes de chamar."""
    argumentos = dict(locals())
    with executar_ferramenta(ctx, "marcar_ganho", escrita=True, argumentos=argumentos, opo_id=oportunidade_id) as s:
        opo = obter_oportunidade_ativa(s, oportunidade_id)
        if status_de(opo) == "ganho":
            return _sem_alteracao(s, opo, "A oportunidade já está marcada como ganha.")
        dados = OportunidadeGanharRequest(
            opoDataFechamento=data_fechamento,
            opoFechadoRecorrencia=_TIPO_PARA_RECORRENCIA[tipo],
            opoValorFechado=valor_fechado,
        )
        atualizada = oportunidade_service.set_oportunidade_status_fechamento(
            s.db, oportunidade_id, "ganho", s.empId, data=dados
        )
        return responder_oportunidade(s, atualizada)


@mcp.tool()
def marcar_perdido(
    ctx: Context,
    oportunidade_id: int,
    motivo_id: int,
    observacao: Annotated[str | None, Field(max_length=10000)] = None,
) -> dict:
    """Marca a oportunidade como PERDIDA com um motivo de perda (IDs em
    listar_cadastros). A observação opcional vai para o histórico. Altera indicadores:
    confirme com o usuário antes de chamar."""
    argumentos = dict(locals())
    with executar_ferramenta(ctx, "marcar_perdido", escrita=True, argumentos=argumentos, opo_id=oportunidade_id) as s:
        opo = obter_oportunidade_ativa(s, oportunidade_id)
        validar_motivo(s, motivo_id)
        if status_de(opo) == "perdido":
            return _sem_alteracao(s, opo, "A oportunidade já está marcada como perdida.")
        # Cada service faz commit próprio: toda validação acontece antes desta linha.
        oportunidade_service.update_oportunidade(s.db, oportunidade_id, OportunidadeUpdate(opoMcaId=motivo_id), s.empId)
        oportunidade_service.set_oportunidade_status_fechamento(s.db, oportunidade_id, "perdido", s.empId)
        if observacao and observacao.strip():
            oportunidade_historico_service.create_historico(
                s.db,
                oportunidade_id,
                OportunidadeHistoricoCreate(ophConteudo=prefixar(s, observacao)),
                company_id=s.empId,
                usu_id=s.usuResponsavelPadraoId,
            )
        return responder_oportunidade(s, obter_oportunidade_ativa(s, oportunidade_id))


@mcp.tool()
def colocar_stand_by(ctx: Context, oportunidade_id: int, data_retorno: date) -> dict:
    """Coloca a oportunidade em STAND-BY até `data_retorno` (hoje ou depois). Na data,
    ela volta sozinha para o funil. Confirme com o usuário antes de chamar."""
    argumentos = dict(locals())
    with executar_ferramenta(ctx, "colocar_stand_by", escrita=True, argumentos=argumentos, opo_id=oportunidade_id) as s:
        obter_oportunidade_ativa(s, oportunidade_id)
        if data_retorno < hoje():
            raise BadRequestError("A data de retorno não pode estar no passado.")
        atualizada = oportunidade_service.set_oportunidade_stand_by(
            s.db, oportunidade_id, OportunidadeStandByRequest(opoDataUltimoContato=data_retorno), s.empId
        )
        return responder_oportunidade(s, atualizada)


@mcp.tool()
def reativar_oportunidade(ctx: Context, oportunidade_id: int) -> dict:
    """Devolve ao funil (status ativo) uma oportunidade ganha, perdida ou em stand-by,
    limpando os dados de fechamento. Confirme com o usuário antes de chamar."""
    argumentos = dict(locals())
    with executar_ferramenta(ctx, "reativar_oportunidade", escrita=True, argumentos=argumentos, opo_id=oportunidade_id) as s:
        opo = obter_oportunidade_ativa(s, oportunidade_id)
        if status_de(opo) == "ativo":
            return _sem_alteracao(s, opo, "A oportunidade já está ativa no funil.")
        atualizada = oportunidade_service.reativar_oportunidade_para_funil(s.db, oportunidade_id, s.empId)
        return responder_oportunidade(s, atualizada)

# Servidor MCP (Claude, n8n)

O SDCRM expõe um servidor MCP para agentes de IA consultarem e operarem o CRM. Ele usa
as mesmas chaves de integração desta página.

## Chave

Crie uma chave **exclusiva** para o MCP em Integrações → Chaves de API:

- `mcp:read` — só consulta (busca, detalhe, histórico, funil, indicadores, metas).
- `mcp:write` — consulta e altera (criar lead, editar, mover etapa, qualificação,
  interações, ganho/perdido/stand-by/reativar).

O "responsável padrão" da chave é quem aparece como autor das anotações feitas pelo MCP.

## Conectar

- **claude.ai** (conector personalizado): URL `https://<host>/crm/api/mcp/<chave>`.
- **Claude Code**: `claude mcp add --transport http sdcrm https://<host>/crm/api/mcp/<chave>`.
- **n8n** (nó MCP Client, Streamable HTTP): URL `https://<host>/crm/api/mcp/` e header
  `X-API-Key: <chave>`.

> A chave vai na URL porque o conector do claude.ai não envia headers próprios, e pode
> aparecer em logs de acesso do proxy. Use uma chave só para o MCP e revogue-a ao trocar
> de conector. Revogar corta o acesso na chamada seguinte.

## Ferramentas

| Ferramenta | Escopo | O que faz |
|---|---|---|
| `contexto` | leitura | Empresa, chave, responsável padrão, data de hoje e pipelines. |
| `listar_cadastros` | leitura | Etapas, produtos, origens, motivos de perda e responsáveis (IDs). |
| `buscar_oportunidades` | leitura | Busca com filtros de texto, status, etapa, responsável, temperatura e último contato. |
| `obter_oportunidade` | leitura | Detalhe, histórico recente, ciclo anterior e link. |
| `listar_historico` | leitura | Histórico paginado. |
| `resumo_funil` | leitura | Quantidade e valor por etapa. |
| `obter_indicadores` | leitura | Cards do painel, meta x realizado, motivos de perda, rankings. |
| `detalhar_indicador` | leitura | Oportunidades por trás de um número do painel (até 100). |
| `obter_metas` | leitura | Metas e realizado do ano. |
| `criar_lead` | escrita | Cria lead com a deduplicação da API. |
| `atualizar_oportunidade` | escrita | Edita dados cadastrais. |
| `mover_etapa` | escrita | Troca de etapa (histórico + webhook). |
| `atualizar_qualificacao` | escrita | Temperatura, lead score, reunião, proposta. |
| `registrar_interacao` | escrita | Anotação no histórico. |
| `marcar_ganho` / `marcar_perdido` / `colocar_stand_by` / `reativar_oportunidade` | escrita | Fechamento. |

Cada chamada aparece no log de requisições como `mcp:<ferramenta>`.
